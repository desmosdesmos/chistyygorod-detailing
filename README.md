# Детейлинг-центр & Автомойка «ЧистыйГород» (Москва) 🚗✨

Официальный современный адаптивный сайт-лендинг для детейлинг-центра и автомойки **«ЧистыйГород»**, расположенного по адресу: **г. Москва, ул. Маломосковская, д. 22, стр. 2** (метро Алексеевская / ВДНХ).

Ссылка на карточку в Яндекс Картах: [https://yandex.ru/maps/-/CXr9ZWZT](https://yandex.ru/maps/-/CXr9ZWZT)

## 🌟 О проекте

Сайт разработан с акцентом на высокую конверсию, премиальную эстетику (темная авто-палитра, акценты золота и неона, стеклянные карточки) и максимальное доверие клиентов:
- **Награда «Хорошее место 2026»** от Яндекс Карт;
- **Рейтинг 4.7** на основе более 760 реальных отзывов и 1 380 оценок;
- Прямой контакт с администратором и управляющим;
- Интерактивный расчет стоимости под конкретный класс автомобиля.

## 🛠 Ключевой функционал

1. **Интерактивный калькулятор стоимости**:
   - Переключение классов авто (1 класс — седаны/хэтчбеки, 2 класс — кроссоверы, 3 класс — внедорожники и минивэны);
   - Мультивыбор услуг (мойка, полировка, керамика 9H, химчистка, озонирование, антидождь);
   - Автоматический пересчет и применение скидки 10% за онлайн-запись;
   - Перенос выбранного набора услуг напрямую в форму онлайн-записи.

2. **Интерактивный слайдер «До / После» (Before / After)**:
   - Возможность перетягивания шторки сравнения состояния ЛКП до восстановительной полировки и после нанесения керамического состава.

3. **Каталог услуг с табами**:
   - Фильтрация по категориям (Мойка кузова, Полировка, Защита и керамика, Химчистка и салон);
   - Подробные карточки услуг с перечнем технологических этапов и ценами.

4. **Галерея работ и студии**:
   - Реальные фотографии боксов, инспекционного света, зоны отдыха и готовых автомобилей с CDN Яндекс Карт;
   - Встроенный Lightbox-просмотр полноразмерных фото при клике.

5. **Блок доверия и реальных отзывов**:
   - Подлинные отзывы автовладельцев с указанием марок автомобилей (BMW 5, Land Cruiser Prado, Audi Q7, Porsche Macan и др.);
   - Прямая ссылка на подтвержденную карточку организации на Яндекс Картах.

6. **Онлайн-запись и модальные окна**:
   - Удобная форма с валидацией, предзаполнением выбранных услуг;
   - Интерактивное окно подтверждения заявки;
   - Быстрый переход в WhatsApp и звонок в один клик.

7. **Адаптивность и мобильный UX**:
   - 100% адаптивный дизайн для смартфонов, планшетов и десктопов;
   - Фиксированная плавающая панель быстрых действий на мобильных устройствах;
   - Автоматическая проверка текущего времени (индикатор "Сейчас открыто до 22:00").

## 🚀 Запуск проекта

Проект не требует сборщиков или сложных зависимостей:
1. Клонируйте репозиторий или скачайте архив:
   ```bash
   git clone https://github.com/desmosdesmos/chistyygorod-detailing.git
   ```
2. Откройте файл `index.html` в любом современном веб-браузере (Chrome, Edge, Safari, Firefox).
3. Либо запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
   и перейдите по адресу `http://localhost:8000`.
